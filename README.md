# Constructor Like Figma

Веб-приложение для создания и редактирования макетов визиток в браузере.  
Пользователь может создавать проекты, открывать их в редакторе, добавлять блоки, менять их стиль, управлять слоями и сохранять макет в базе данных.

---

## О проекте

Проект представляет собой собственный мини-конструктор интерфейсов, вдохновлённый логикой Figma и простых no-code редакторов.  
Основная идея — дать пользователю возможность визуально собирать макет из блоков без ручной вёрстки.

Система состоит из:

- личного кабинета с проектами
- редактора макета
- системы сохранения layout-данных
- работы с шаблонами
- редактирования текста, размеров, фона, изображений и слоёв

---

## Основные возможности

### Личный кабинет
- регистрация и авторизация пользователя
- просмотр списка своих проектов
- создание нового макета
- удаление макета
- редактирование описания проекта
- переход в редактор конструктора

### Редактор макета
- добавление текстовых блоков
- добавление изображений
- выбор готовых шаблонов
- изменение текста блока
- изменение цвета текста и фона
- изменение размеров блока
- изменение скругления
- установка фонового изображения для блока
- установка фонового изображения для полотна
- удаление блока
- перемещение блоков drag-and-drop
- изменение позиции по X/Y
- выравнивание по полотну
- дублирование блока
- удаление через кнопку и клавиши
- переключение светлой и тёмной темы полотна

### Работа со слоями
- отображение списка всех элементов макета
- автонумерация слоёв (`text #1`, `image #2` и т.д.)
- выбор слоя из панели
- изменение порядка слоёв
- перемещение слоя выше / ниже / вверх / вниз
- drag-and-drop сортировка слоёв

### Сохранение
- сохранение макета в БД
- загрузка ранее сохранённого макета
- сохранение компонентов с позициями, размерами, стилями и содержимым

## Архитектура проекта

Примерная логика проекта:

- **backend** — HTTP-сервер на Go
- **repository** — работа с базой данных
- **handlers** — обработчики API и страниц
- **static** — фронтенд-часть (HTML, CSS, JS)
- **database** — таблицы пользователей и макетов

---

## Структура данных макета

Каждый макет хранится как JSON-объект.  
Пример структуры:

```json
{
  "id": 1,
  "components": [
    {
      "id": 123,
      "type": "text",
      "position": { "x": 50, "y": 50 },
      "size": { "width": 200, "height": 50 },
      "z_index": 1,
      "content": { "text": "Hello world" },
      "style": {
        "background_color": "#ffffff",
        "color": "#000000",
        "font_size": "16px",
        "background_image": "",
        "border_radius": "0px"
      }
    }
  ],
  "canvas_background": ""
}
```

## База данных

Проект использует PostgreSQL.

Пример таблицы макетов:

```sql
CREATE TABLE layouts (
    id SERIAL PRIMARY KEY,
    user_id INT NOT NULL,
    name TEXT NOT NULL,
    description TEXT DEFAULT '',
    layout JSONB NOT NULL DEFAULT '{}'::jsonb,
    created_at TIMESTAMP DEFAULT now()
);
```

## Основные API endpoints

### Пользователь
- `GET /api/me` — получить текущего пользователя

### Макеты
- `GET /api/layouts/list` — список макетов пользователя  
- `GET /api/layouts/get?id=...` — получить макет  
- `POST /api/layouts/create` — создать новый макет  
- `POST /api/layouts/save?id=...` — сохранить макет  
- `POST /api/layouts/delete` — удалить макет  
- `POST /api/layouts/update-description` — обновить описание  

### Страницы
- `/home` — личный кабинет  
- `/constructor?id=...` — редактор макета  
- `/login`  
- `/register`

## Как запустить проект

### 1. Клонировать репозиторий
```bash
git clone <your-repo-url>
cd <project-folder>
```

### 2. Настроить PostgreSQL
Создать БД и таблицы.

### 3. Указать строку подключения
```bash
export DATABASE_DSN="postgres://user:password@localhost:5432/dbname?sslmode=disable"
```

### 4. Запустить сервер
```bash
go run main.go
```

После запуска приложение будет доступно по адресу:  
http://localhost:8080

---

## Сценарий использования

1. Пользователь регистрируется или входит в систему  
2. Попадает в личный кабинет  
3. Создаёт новый макет  
4. Открывает его в редакторе  
5. Добавляет текст, изображения и шаблоны  
6. Настраивает оформление и слои  
7. Сохраняет результат  
8. Возвращается к проекту позже и продолжает редактирование  

---

## Особенности реализации

- данные макета сохраняются не как HTML, а как структурированный JSON  
- элементы рендерятся динамически через JavaScript  
- стили каждого блока управляются отдельно  
- редактор не зависит от сторонних конструкторов  
- архитектура позволяет масштабировать функциональность
